A voice assistant

Nova Voice starts speaking before its answer is finished, and stops the moment you cut in. It runs on your machine with Claude or a free local Ollama model.

From your voice to its voice

The goal is perceived latency and natural turn-taking, so every stage hands off as early as it can.

  1. Wake word

    openwakeword listens for hey jarvis (or alexa, hey mycroft). Nothing else is processed until it hears it.

  2. Record

    Adaptive endpointing measures the room's noise and ends your turn after 0.8 s of silence, instead of using a fixed magic number.

  3. Transcribe

    faster-whisper runs locally. Trailing silence is trimmed before it sees the audio.

  4. Think

    Claude or a local Ollama model streams tokens back and can call tools mid-answer.

  5. Chunk

    The token stream is cut into speakable sentences the moment each one completes. The cutter knows Dr., U.S., 3.5 and list markers are not sentence ends.

  6. Speak

    edge-tts synthesizes chunk two while chunk one is playing, through an output stream that stops within about 64 ms.

  7. Listen while talking

    A barge-in monitor watches the mic. Sustained speech stops the voice, cancels generation, and keeps the words you already said for the next turn.

Details that make it feel human

Interruptible playback
Audio goes out in small blocks, so stop() silences the voice almost instantly. A blocking player cannot do that.
Barge-in
Speak over the assistant and it stops, cancels the reply, and prepends what it already heard from you to the next recording.
Min-speech gate
A click or a cough no longer starts a recording.
Speech cleaning
Markdown, URLs and list markers are stripped before synthesis, so it never reads out asterisks.
Fault isolation
One failed sentence, tool crash or API error does not stall the turn. History is rolled back so the next turn stays valid.
Graceful fallbacks
After three failures in a row, a broken wake-word model drops to push-to-talk and a missing mic drops to text-only, instead of crashing.
Per-stage timing
Every reply prints a [timing] line: wake, endpoint wait, STT, first token, first audio, and total.
Turn-safe memory
The rolling window trims only at user-turn boundaries, so a tool call is never separated from its result.

Pick your brain

Claude

Set ANTHROPIC_API_KEY for the hosted model with tool use.

Ollama, fully local

Set LLM_PROVIDER=ollama and run ollama pull llama3.2. Free, and nothing leaves your machine except web search.

Tools the assistant can call:

  • set_reminder
  • list_reminders
  • cancel_reminder
  • search_web

Reminders use timezone-aware timestamps and atomic file writes. Web results are truncated, cached briefly and labelled as untrusted text in the prompt.

Honest by design

125unit tests that need no mic, speaker, API key or network
2LLM backends tested through one shared streaming and tool loop
0performance numbers in the docs that you cannot re-run yourself

Barge-in has no echo cancellation. On loudspeakers the assistant's own voice can leak into the mic, so use headphones or raise BARGE_IN_RMS. That is why the feature is opt-in. Benchmark and eval scripts live in the repo and write their results back into it.

Run it

Python 3, a microphone, and about 150 MB for the first Whisper download.

# get it
git clone https://github.com/urjanandy23/Nova_Voice.git
cd Nova_Voice
python -m venv venv
venv\Scripts\activate      # macOS/Linux: source venv/bin/activate
pip install -r requirements.txt

# choose a brain: set ANTHROPIC_API_KEY, or use local Ollama
copy .env.example .env     # macOS/Linux: cp
ollama pull llama3.2

# talk to it
python main.py --barge-in
  • python main.py: say "hey jarvis"
  • --push-to-talk: press Enter, then speak
  • --hybrid: speak or type each turn
  • --text-only: no mic, reply still spoken
